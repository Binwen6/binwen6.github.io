# 第二章 感知原理

本章回答一个核心问题：**物联网/智能感知系统如何"感知"世界**。三条并列的技术路线构成全章骨架：

1. **传感器类节点** —— 用专门的敏感元件把物理/化学/生物量转成电信号；
2. **非传感器类节点** —— 不依赖传统传感器，而是借助**无线通信技术**实现感知（识别、定位、动作识别等）；
3. **多模态融合** —— 把多种模态的数据综合起来提升理解能力（Part2）。

其中 **RFID 防冲突算法** 和 **毫米波 FMCW** 是两个需要展开掌握的核心算法。

接着讲完**其他无线传感技术**（毫米波生命体征、UWB、激光雷达、红外），再讲**无线个域网**（蓝牙/ZigBee/LoRa），最后是第三条主线**多模态融合**。其中 **UWB 测距定位** 和 **多模态融合的关键步骤** 是两个核心考点。

## 一、传感器类节点

### 1. 传感器的定义与组成（必考概念）

**定义**：能感受规定的被测量信息，并按一定规律转换成**可用信号**的器件或装置。

**三段式组成**（这是考点，要记住信号流向）：

> 被测量 →【敏感元件】→【转换元件】→【转换电路】→ 电量输出

- **敏感元件**：直接感受被测量，输出与被测量成确定关系的某一物理量；
- **转换元件**：把敏感元件的输出转换成电路参量（电阻、电容等）；
- **转换电路**：把电路参量转换成可传输/测量的电量（电压、电流）。
- 由于输出信号微弱，还需信号调理电路放大调制；现代多与敏感元件集成在同一芯片。

**分类（6 个维度，了解即可，能举例最佳）**：按检测范畴（物理/化学/生物量）、按输出信号（模拟/数字）、按结构（结构型/物性型/复合型）、按功能（单功能/多功能/智能）、按转换原理（机—电/光—电/热—电/磁—电/电化学）、按能源（有源/无源）。

### 2. 手机中的典型传感器（理解原理即可）

|传感器|工作原理（速记）|典型应用|
|---|---|---|
|光线|感测环境光强度|自动调屏幕亮度、省电、口袋防误触|
|距离|红外LED发射→物体反射→测接收强度|贴耳通话灭屏、手套模式|
|重力|**压电效应**，正交两方向电压算水平方向|横竖屏切换、赛车游戏|
|加速度|三维度确定加速度方向|计步、判断朝向|
|指纹|微电场与电容间微电流，波峰波谷形成电容高低差|解锁、加密、支付|
|气压|薄膜形变→电阻/电容变化|测海拔（误差可校到~1m）、辅助GPS定楼层|
|心率|LED照射手指，血流使红光亮度周期变化|心率监测|

## 二、非传感器类节点

### 1. 总体分类（按无线网络）

|网络类型|代表技术|特征|
|---|---|---|
|互联网/电信网|IPv6|物联网核心网络，解决终端数量限制|
|无线宽带网|WiFi、WiMAX|覆盖广、速度快、廉价|
|无线低速网|ZigBee、蓝牙、红外|适应低速率/低功耗/低算力节点|
|移动通信网|4G/5G、NB-IoT|"全面、随时、随地"传输|

三大挑战：**环境复杂多变、节点功能单一、技术互通困难**。

### 2. 识别技术

#### （1）一维条码

- 本质：一组按规则排列的**条、空**及对应字符组成的符号；数据容量约 **30 字符**，只含字母数字。
- **结构次序（考点）**：静区(前) → 起始符 → 数据符 →（中间分隔符，主要用于EAN码）→ 校验符 → 终止符 → 静区(后)。
- 商品条码：EAN、UPC；物流条码：128码、ITF、三九码、库德巴码。
- **UPC-A**：每个字码由 7 个模组组成（7位二进制），0=空白、1=线条；**UPC-E** 是 UPC-A 的压缩短码，6位数字、无中间线。

#### （2）二维码

- 本质：用几何图形，"点"表示二进制1、"空"表示0。
- **七大优点**：可靠性强（约15000字符1错）、效率高、成本低、易制作、灵活实用、高密度、**纠错功能**（部分损坏仍可还原）。
- **两类码制（考点）**：
    - **线性堆叠式**：一维码纵向堆叠，如 PDF417、Code 16K/49；
    - **矩阵式**：矩形空间内黑白像素分布编码，如 **QR Code**、Data Matrix、Aztec、Maxi Code。
- **QR码重点**：横纵双向存信息；三个角有**寻象图形**支持360°高速识读；13bit表示一个汉字（比其他二维码效率高20%）；规格版本1（21×21）到版本40（177×177），每版每边+4模块。
- **QR纠错四等级（要记）**：L≈7%、M≈15%、Q≈25%、H≈30%。

#### （3）RFID（射频识别，重点）

**概念**：非接触式自动识别技术。**组成四部分**：标签（天线+芯片）、阅读器、天线、后台系统。

**相比条码的优势**：非视距扫描（与光线无关）、可多标签同时识别（效率高）。

**两种分类（考点表）**：

按**频段**：

| |低频|高频|超高频|
|---|---|---|---|
|频率|125/134KHz|13.56MHz|860~960MHz|
|场景|动物识别|门禁卡|物流仓储|
|通信距离|~1cm|<1cm|~10m|
|通信方式|互感耦合|互感耦合|**反向散射**|

按**供能方式**：主动式（自带电池、贵、有算力，~几十米）／半被动式（电池+阅读器供能）／被动式（**阅读器供能、无电池、便宜、算力有限**，~十米）。

> **研究重点：超高频被动式RFID**——发展最快、最具代表性。优点：非视距、多标签、能耗低、价格低；缺点：存储小、功能弱。

**工作原理**：标签进入阅读器工作范围 → 阅读器发射射频信号 → 标签天线产生感应电流激活内部电路 → 无源标签回送信号 / 有源标签主动发信号 → 阅读器处理后上传控制系统。

**两种耦合方式**：

- **电感耦合**：阅读器线圈L1的高频电流产磁场，磁力线穿过标签线圈L2感应出电压供电；标签通过改变负载电阻（负载调制），变化经L2映射回L1，阅读器解调获得数据。（近距离、低/高频）
- **电磁反向散射耦合**：标签反射/散射阅读器信号（远距离、超高频）。

### ★ 核心算法：RFID 防冲突（防碰撞）算法

这是 Part1 最重要的考点，配套有 `计算题.pdf`，需要会算吞吐率、会比较复杂度。

**为什么需要**：阅读器范围内常有多个标签，发命令后多标签同时响应，在共享信道上**碰撞**，阅读器无法辨认。需要算法把冲突标签区分开，逐个通信。（注：还有阅读器冲突与标签冲突两类）

**为何 CSMA/CA 不适用**：CSMA/CA 要求发送前先监听信道（Wi-Fi 802.11 用），但 RFID 标签**能力弱、无法有效监听**，故不适用。

RFID 主要用 **ALOHA 类** 和 **二进制树类** 两大族算法。

#### A. 纯 ALOHA（有数据就发）

**吞吐率推导（要会）**：定义吞吐率 S（单位时间成功发送的平均帧数，0<S<1）、网络负载 G（单位时间所有标签发送的平均帧数，G≥S）、重发帧数 R，有 **G = S + R**，**S = P·G**（P为发送成功概率）。

- 一帧时长 T，**易冲突区间为 2T**（前后各一个帧时间内不能有其他帧）；
- 标签到达服从**泊松分布**，2T 内平均到达数 m = 2G，成功条件即 2T 内无其他帧：

$$P(0)=e^{-2G}$$

- 于是吞吐率：

$$\boxed{S = G,e^{-2G}}$$

- 求导得极值在 **G = 0.5**，最大吞吐率 **S_max = 0.5·e⁻¹ ≈ 0.184**。
- 复杂度：时间复杂度 **G·T**（阅读器视角，不论成败都要读），传输复杂度 **G·T**（标签视角），最优 G=0.5。

#### B. 基于帧的时隙 ALOHA（FSA / FMA）

时间分**帧**，每帧分多个**时隙**，标签随机选时隙发送。设时隙数 p、标签数 n：

- 单标签在某时隙成功（独占）的概率：

$$P=\frac{1}{p}\left(1-\frac{1}{p}\right)^{n-1}$$

- 吞吐率 $S = n\cdot P$；当 **p = n** 时取最大，$S=(1-\tfrac1n)^{n-1}\to e^{-1}\approx 0.368$（比纯ALOHA高一倍）。
- 复杂度上界：时间 **p×t + 估算标签数的时间**，传输 **n×t**。需标签可写（8/16bit内存计数指示响应时隙）。
- **Q算法**：自适应调帧长——冲突时隙过多则提前结束、换更大帧；空闲时隙过多则换更小帧（Qfp帧参数、C常量0.1~0.5）。超高频系统广泛使用。

#### C. 二进制树类

- **随机二进制树**：每标签维护计数器（初值0），计数器为0才发送；冲突时隙中相关标签从{0,1}随机选一个加到计数器上。过程类似二叉树**中序遍历**，**不会饿死**，但需维护计数器。时间复杂度 **O(n)**（节点总数2n−1）；通信复杂度平均 **O(n log n)**、最差 **O(n²)**。
- **查询二进制树**：无状态协议。阅读器广播二进制**前缀**，标签把ID前几位与前缀比较，相同则响应。类似建查询二叉树，**不会饿死**、可用于无可写存储标签，但受ID长度与分布影响。时间复杂度平均 **O(n)**，通信复杂度平均 **O(n log n)**。

#### D. 性能对比总表（必考）

|算法|时间复杂度|传输复杂度|需标签可写|
|---|---|---|---|
|纯ALOHA|G·T|G·T|否|
|帧时隙ALOHA(FSA)|p×t + 估算标签时间|n×t|是|
|随机二进制树|O(n)|n未知 O(n log n)/n已知 O(n)|是|
|查询二进制树|平均 O(n)|平均 O(n log n)|否|

> 两族优缺点：ALOHA 类——算法简单、可统计分析、识别性能好，但**最坏时延趋于∞、会标签饿死**；二进制树类——算法简单、**不饿死**，但时延受 ID 分布与长度影响。

**商用通信协议（时隙ALOHA）**：阅读器发 Query → 标签在时隙回 **RN16**（16位随机数）→ 阅读器 **ACK** 回该RN16 → 标签发 **EPC**（电子产品码，最高128bit）。

- 思考题：**为何先发RN16？** 用随机数标识本次会话、避免直接暴露EPC并用于碰撞检测与确认握手（同一时隙只有一个标签的RN16能被正确ACK，从而完成单标签隔离）。

### 3. 无线局域网 Wi-Fi

**通信原理**：WLAN 用电磁波作载体，射频发射器产生交变电流→铜导线→天线→辐射出射频。

**频段（考点）**：2.4GHz 与 5GHz，属 **ISM 频段**（工业/科学/医疗，免许可证）。

- 2.4GHz（2.4~2.4835GHz，83.5MHz）划 **13 个相互交叠信道**，其中 **1、6、11 为互不交叠的 3 个独立信道**；部署AP用**蜂窝式**布局、相邻AP用独立信道避免同频干扰。
- 5GHz 划 24 个 20MHz 独立信道；802.11n 可把相邻两个20MHz**绑定成40MHz**倍增速率。
- **OFDM**（正交频分复用）：把信道分成若干正交子信道，高速串行→并行低速子流，抗多径衰落、支持多用户。

**MIMO（多入多出）**：按收发天线分 SISO/SIMO/MISO/MIMO；记法 A×B:C（发射×接收:空间流）。两个概念——

- **传输分集**：不同天线发**相同**内容，速率不变、可靠性与覆盖↑；
- **空间复用**：不同天线发**不同**内容，可靠性与覆盖不变、速率↑。

**标准**：IEEE 802.11 系列。2.4GHz 支持 b/g/n/ax；5GHz 支持 a/n/ac/ax。

**帧（考点）**：

- 帧结构关键字段：Protocol Version（目前0=802.11）、**Type**、Subtype；
- **帧类型**：**00 管理帧**（建立连接、扫描/连接/退出）、**01 控制帧**（连接控制、应答、载波监听维护）、**10 数据帧**；
- **STA 接入六阶段**：扫描（主动/被动）→ 链路认证 → 关联（协商速率/信道/加密）→ 接入认证（PSK / 802.1X）→ 地址分配（DHCP）→ 用户认证（802.1X / MAC / Portal）。

### 4. 其他无线传感技术：毫米波（重点）

**毫米波（mmWave）**：波长 1~10mm（频率 30~300GHz），介于微波与红外之间。

- **窗口频率**：24GHz、60GHz、77GHz 衰减较小；主流 24GHz（短距，盲点探测 BSD）与 77GHz（中长程，自适应巡航 ACC）；**频率越高，距离/速度分辨率越高**。
- 优势：受云雾烟尘小雨雪影响小、**全天候**；分辨率高且比激光雷达便宜；作用距离远。
- 分类：按用途（军用/民用）、按波形（脉冲/连续波/**调频连续波FMCW**）、按信号来源（主动发射 vs 被动接收，如安检雷达）。

**★ FMCW 工作原理（三种测量，需理解公式关系）**

基本框架：合成器生成**线性调频脉冲（chirp，频率随时间线性升高）**→ TX 发射 → 物体反射 → RX 接收 → **混频器**把 RX、TX 合并生成**中频信号（IF）**。

- **距离测量**：物体距离 d，往返时延 τ=2d/c，IF 是一个频率正比于 d 的正弦波：

$$f_{IF}=S\cdot\frac{2d}{c}\ \Rightarrow\ d=\frac{c,f_{IF}}{2S}$$

（S为调频斜率）。多个物体→对IF做FFT，多个峰值对应多个距离。

- **速度测量**：发**两个**chirp，物体微小移动导致IF**相位差**：

$$\Delta\phi=\frac{4\pi v,T_c}{\lambda}\ \Rightarrow\ v=\frac{\lambda,\Delta\phi}{4\pi T_c}$$

注意局限：若**多个物体同距离、不同速度**，距离FFT只产生单个峰、相位比较失效——此时需发**N个等间隔chirp**做多普勒FFT区分。

- **角度测量（AOA）**：至少用**两个接收天线**，物体到两天线的距离差导致FFT峰值**相位变化**，由此估角度；估计精度依赖AOA，**θ 较小时精度更高**。

## 一、毫米波补充：生命体征监测

承接 Part1 的 FMCW 三测量，毫米波还能做**非接触生命体征监测**。

- **4D 毫米波雷达**：与普通 77GHz 测速测角原理相同，区别在收发天线数、馈线电路、信号处理算法，性能上多了**相对垂直角度**的探测。
- **原理**：心脏泵血、胸腔起伏会引起反射信号**相位的周期性变化**——波峰间隔对应呼吸周期，心跳叠加在呼吸波形上改变其幅度。通过连续 N 帧采集相位变化即可解出呼吸、心率。

## 二、UWB（超宽带，重点）

**定义**：通过**极窄脉冲**（小于 ns 级）进行调制的无线通信技术，又称脉冲无线电（IR-UWB）。

- **"超宽带"的来历**：FCC 分配频带 3.1~10.6GHz，共 **7.5GHz** 可用带宽；载波带宽达 **500MHz**。

**四大特点**：①高带宽高速率（带宽>1GHz，几十~几百Mbps）；②**低功耗低发射功率**（通常<1mW）；③抗干扰强（跳时扩频分散在宽频带）；④**精确定位（厘米级）**，适合室内定位。

**信号特征（与窄带对比，考点）**：传统通信用**连续波载波**+调幅/调频，能量集中在窄频带；UWB 不需连续载波，仅发极窄脉冲，通过改变脉冲的**幅度/时间/相位**加载信息，频域上**带宽极大、每个频点功率极低**。关键优势：IR-UWB 能**准确分离首达信号与多径反射信号**，而窄带信号不具备该能力——这正是 UWB 室内定位精度高的根本原因。

**与其他技术对比**：蓝牙只能测信号强度不能测距/位置；GPS 室内失效（精度~5m且更差）；NFC 范围仅 4cm；Wi-Fi 主要靠信号强度估距（多数未商用）。**UWB 是目前最精确的室内定位方式（精度可达约 10cm）**。

### ★ UWB 三种测距定位方式（IEEE 802.15.4z-2020）

#### 1）SS-TWR 单边双向测距（Single-Sided Two-Way Ranging）

测量**单个消息的往返时间**：A 发起→B 响应。各设备用本地时钟精确测量收发时间，飞行时间：

$$T_{prop}=\frac{T_{round}-T_{reply}}{2}$$

- **缺陷**：A、B 时钟各有误差，TOF 误差**随应答时间 T_reply 增大而增大**；**每 1ns 的 TOF 误差 ≈ 30cm 测距误差**。
- A 获取 T_reply 的三种方式：①B 额外发一条消息告知 T_reply；②B 把 T_reply 嵌入响应报文；③T_reply 为预先约定的固定已知值（精度取决于 B 对发送时间的控制精度）。

#### 2）DS-TWR 双边双向测距（Double-Sided Two-Way Ranging）

SS-TWR 的扩展，**组合两个往返时间**，即使时钟频偏未校正、响应延迟较长，也能给出较小误差的 TOF。

- **四信息交互**：A、B 各自精确测量收发时间，公式**不要求对称的回复时间**，20ppm 晶振+不对称响应时即使如此，时钟引起的误差也在皮秒级。
- **三信息交互（简化）**：用第一次往返的回复作为第二次往返的启动，把消息减为 3 条。
- **优点**：自动补偿两设备时钟偏差、精度较高、易扩展为多锚点；**缺点**：交互信息多、功耗较高。
- 多锚点示例：手机为 A，多个车端锚点为 B、C，组建测距网络。

#### 3）OWR/TDOA 单向测距/到达时间差

基于消息的**相对到达时间**定位移动设备。两种方式：①移动设备周期性广播消息（blink），到达多个**已同步**的固定节点，比较各自到达时间；②多个同步节点按已知时间偏移顺序广播。

- **原理**：每一对同步节点的到达时间差把设备约束在一条**双曲面（双曲线）**上，所有双曲面的**交点**即设备位置估计。

> 速记对比：SS-TWR 简单但精度低（受时钟漂移）；DS-TWR 精度高、抗时钟偏差但功耗高；TDOA 需节点严格同步、适合移动端低功耗广播。

**UWB 雷达成像**：超短脉冲、带宽达几 GHz，脉宽短、峰值功率高、可穿透障碍物，用于穿墙雷达（军事）、非接触生命监测（医疗）、车内活体/脚踢检测（车载）。

## 三、激光雷达（Lidar）

**定义**：通过发射/接收激光束实现目标检测的感知元件（Laser Detecting and Ranging）。1 秒可生成几十万~数百万个**点云**，角度分辨率和测距精度极高，反射率还能区分材质。

**按扫描方式分类（考点）**：

|类型|结构|特点|
|---|---|---|
|机械式|收发模块随电机360°旋转|技术成熟、360°环境重构清晰；但线束多、需人工调教、成本高、可靠性差、体积大、寿命短（1000~3000h<车规13000h）|
|半固态(MEMS)|收发固定，靠**微振镜**扫描|体积小、成本可降；但微振镜对振动敏感、FOV小（<120°）、探测距离短（~50m），多用于补盲/前向|
|固态(OPA)|完全无运动部件，光学相控阵|利用光的相干性、控制相位差实现扫描，耐久、体积小；但对算力/工艺要求极高（阵元尺寸≤半波长），难车规量产|

**按测距方式分类（考点）**：

- **三角测距法**：靠三角形原理，距离变化→感光位置变化。精度高但范围近（室内导航、近距检测）。
- **dTOF（直接飞行时间）**：直接测发射与回波的时间差，$d=\tfrac{c\cdot T}{2}$。响应快、精度高，适合**远距离**，主流方案。
- **FMCW（相干测距）**：调制光强，回波与参考光相干拍频得相位差→间接得飞行时间。可直接测速、抗干扰强；但远距衰减影响精度，适合中短距。技术成熟度低，未大规模商用。
- **iTOF（间隔飞行时间）**：测发射/接收正弦波（方波）的相位差。中短距精度高，对器件要求比 dTOF 低，用于机器人/智能家居/AR/VR。

## 四、红外热成像

**红外线**：电磁波按波长分（无线电波/微波/红外/可见光/紫外/X/γ），人眼仅能感知 0.38~0.76μm 可见光，无法直接看红外。

**热辐射基本原理（考点）**：

- 任何温度高于**绝对零度（0K，−273.15℃）**的物体都以电磁波（主要是红外线）向外辐射能量；
- **斯特藩-玻尔兹曼定律**：热辐射总能量与物体温度的**四次方**成正比。

**热像仪分类**：按探测器工作温度分**制冷型**与**非制冷型**。

**特点**：被动式非接触（隐蔽性强）、夜视、全天候（不受雨雪雾霾影响）、穿透烟尘强、高灵敏高精度、多目标跟踪。医学上用于炎症、组织损伤、肿瘤的早期筛查（基于细胞代谢热）。

## 五、无线个域网（蓝牙 / ZigBee / LoRa）

### 1. 蓝牙

**发展史（要点）**：1.0（1999，有泄露风险）→2.0（2004，双工）→3.0（2009，高速、挤占WiFi、功耗成本↑）→**4.0（2010，引入 BLE 低功耗概念）**→5.0（2016，低功耗下更强传输，主流）。

**传统蓝牙 vs 低功耗蓝牙（BLE）**：

- 信道：传统 **79 个**信道（2.402+k MHz，k=0~78）；BLE **40 个**信道（2402+2k MHz，k=0~39），其中 **37/38/39 为广播信道且不连续**。
- **经典蓝牙**：为传输**声音**设计，用于电话/耳机/音箱，数据量大；
- **BLE**：跳频、数据量小但功耗低、距离远，用于共享单车锁、可穿戴、IoT、键鼠等电池设备。
- **注意**：BLE 设备与经典蓝牙设备**不能相互通信**。

**BLE 六大特点**：①高可靠（差错检测纠正、自适应跳频抗 2.4G 串扰）；②低成本低功耗（4.0 功耗较传统降 **90%**，用深度睡眠替代空闲态）；③快速启动（连接从 6s 降到 **3ms**）；④传输距离远（BLE4.0 约 50~100m，BLE5.0 最大 800m）；⑤速率分 Raw（4.2:1Mbps / 5.0:2Mbps）与 Application（受连接间隔/帧间隔限制达不到理论值）；⑥高安全（**AES-128 CCM** 加密认证）。

### 2. ZigBee

**底层**：IEEE **802.15.4**（MAC+PHY）。频段：868MHz（欧）/915MHz（美）/**2.4GHz（全球）**。

**三种设备类型**：**协调器** Coordinator（启动配置网络，每网必有1个）、**路由器** Router（允许设备接入、转发）、**终端** End-device（无路由功能、低功耗、可休眠唤醒——ZigBee 低功耗主要体现在此）。

**三种拓扑**：星状（附属节点只能与中心通信，效率可靠性低）→树状（多星状组合，子节点只与父节点通信、多跳，容量健壮性提升）→**网状 mesh**（相邻路由可直接通信、动态灵活、最能发挥自组织优势）。

**特点速记**：低功耗低速率（20~250 kbit/s，两节5号电池跑6~24月）、短延迟（休眠激活15ms、入网延迟30ms）短距离（10~100m）、大容量（**多达 65000 节点**）、免许可ISM频段、高可靠（AES-128、碰撞避免、自修复路由）、自组织多跳。

### 3. LoRa

- 起源：法国 Cycleo（2009）扩频无线调制专利。
- **调制方法（考点）**：**基于 Chirp 的线性扩频调制**，用线性调频脉冲编码信息。
- **调制参数**：速率、带宽 **BW**、**扩频因子 SF**（一个符号含几位数据）、**编码率 CR**（添加的冗余位数）、休眠时间。
- 五大特点：**远距离**（空旷数公里、城市1~2km）、低功耗（休眠+自适应速率，电池续航数月数年）、高抗干扰（扩频，误码率低）、大容量（不同SF/信道，单网关数千~数万节点）、低成本（无需大量基站，模块几元~几十元）。

> **个域网/局域网横向对比（高频考点）**：Wi-Fi（高速、30~100m、互联网接入）、经典蓝牙（音频、2~10m）、BLE（低功耗、50~100m）、ZigBee（自组网mesh、低速、10~100m、大容量）、LoRa（超远距km级、超低功耗、超低速率）。记忆主线：**速率↑则距离/续航↓**，LoRa 牺牲速率换距离与续航，Wi-Fi 反之。

## 六、多模态融合（第三条主线，重点）

**背景**：自然界感知是异构多传感融合（多维感知+记忆+先验+规则+推理）。典型无人车单日感知数据 **>4TB**（摄像头20-60MB/s、激光雷达10-70MB/s、毫米波10kB/s 等），数据规模庞大、难以有效融合优选（2016 特斯拉因摄像头误判且忽略毫米波结果致死的案例，说明融合的必要性）。

**定义**：集合来自不同模态（视觉/听觉/文本等）的数据以提升信息处理与理解能力的技术。

**两个重要原则（必考）**：

- **互补性原则**：一个模态包含其他模态缺乏的信息，综合后更全面地表述目标；
- **一致性原则**：不同模态共享某些一致的语义信息，学习中最大化模态间一致性。

**五种模态及特征速记**：图像（空间分辨率/RGB/纹理边缘）、文本（词汇/语义Word2Vec-BERT/句法/上下文LSTM-Transformer）、音频（时域/频域傅里叶/时频MFCC/语音特征）、视频（帧级+时序+光流）、传感器（时间序列/频域/多传感）。

### ★ 多模态融合的四个关键步骤（核心考点）

1. **表征（Representation）**：找对多模态信息的统一表示。两类——
    - **Joint 联合（单塔结构）**：融合多输入 x=f(x₁,x₂)，注重**互补性**，优化目标是预测任务性能；
    - **Coordinated 协作（双塔结构）**：不融合，把各模态映射到协作空间使 f(x₁)~g(x₂)，建模模态间**相关性**，优化目标是协作关系（如最小化 cosine 距离）。
2. **翻译（Translation）**：一个模态映射到另一个模态。分 example-based（有候选集，如检索）与 generative（Encoder-Decoder 生成）。
3. **对齐（Alignment）**：找模态子成分间的关系（某词对应某图像区域）。分**显式对齐**（无监督/监督，直接建对应）与**隐式对齐**（注意力对齐、语义对齐，Attention 首当其冲）。
4. **融合（Fusion）**：整合信息。分 model-agnostic、model-based、Co-learning。

### ★ 按层次的三级融合模式（核心考点）

|融合层次|时机|说明|
|---|---|---|
|**数据级**（Data-Level）|预处理阶段直接合并原始数据|适用高度相关互补的数据|
|**特征级**（Feature-Level）|特征提取之后、决策之前|各模态分别提特征再在特征层融合|
|**目标级/决策级**（Decision-Level）|各单模态决策后整合结果|适用多模型/多传感器/多专家结果综合|

**典型任务（了解）**：跨模态定位（Visual Grounding、Temporal Language Localization）、跨模态生成（Image Captioning、VQA视觉问答、Text-to-Image、视听语音识别、声源分离、Text-to-Speech）。 **数据集（了解）**：MS COCO Captions（物体识别）、RefCOCO/+/g（指称表达 REC）、nuScenes（自动驾驶，6相机+5毫米波雷达360°）、XRF V2（Wi-Fi+IMU+RGBD+IR 动作识别，西交本课题组工作）。

---

> **算法类（会推导/会算）**：RFID 防冲突 ALOHA 吞吐率 ＞ 毫米波 FMCW 三测量 ＞ UWB SS/DS-TWR 测距 **结构/分类类（会对比）**：多模态四步骤+三级融合 ＞ 个域网/局域网横向对比 ＞ RFID 频段/供能分类 ＞ 激光雷达分类 ＞ QR 纠错与码制 ＞ Wi-Fi 帧类型/接入六阶段 **概念类（会默写）**：传感器三段式、二维码两类码制、热辐射斯特藩-玻尔兹曼、多模态两原则

## 第一部分：室内定位技术（以 RFID 为例）

### 1. 室内定位的特点（为何室内难做）

与室外 GPS 不同，室内定位强调六点：①**定位精度**更高更好；②**稳健性**（环境复杂多变要自适应）；③**安全性**（多为个人用户）；④**方向判断**（方位与运动趋势）；⑤**标志识别**（利用室内标志性目标提精度）；⑥**复杂度**应较低。

常见室内定位技术：红外、超声波、蓝牙、**RFID**、WiFi、陀螺仪、计算机视觉、磁场等。

### 2. RFID 定位原理（11.2）——三大类信号特征

RFID 定位的本质是**从标签信号里提取某种特征，再反推位置**。按所用特征分三大类（这是后面所有方法的分类骨架）：

|特征类别|思路|包含方法|
|---|---|---|
|**信号强度**|感知场景做定位解读|RSSI空间指纹法、信号传播模型法、信号扰动法|
|**信号相位**|用三角测量或感知相位变化规律|相位差双曲线法、到达角法、相位空间分布概率法、相位时空特征法|
|**其他特征**|利用其他物理量|多径效应轮廓、信号传输时间|

### 3. RFID 单标签定位技术（11.3，核心展开）

#### （1）基于信号强度

- **a) RSSI 空间指纹法**：离线在各位置采集 RSSI 建指纹库，在线匹配最相近指纹定位。精度低、耗时高、需参考标签。
- **b) 信号传播模型法**：以经典射频电磁波传播模型为基础。流程：①各天线扫描所有标签收 RSSI →②**子区域检测**（按最大 RSSI 判断目标所在子区，如场景四角放阅读器分四区）→③用参考标签估计当前环境**传播模型参数**，据此算标签到各阅读器距离 →④多次估计去异常取均值 →⑤以阅读器为圆心、距离为半径作圆，两两相交、去异常取中心为位置。**缺点**：参数估计变化大、易受硬件与环境影响、对场景变动极敏感，近年逐步淘汰，但易部署在低要求场景仍有价值。
- **c) 信号扰动法**：精度高但耗时高，仅需 1 天线、需参考标签。

#### （2）基于信号相位（精度普遍更高）

- **a) 相位差双曲线法**（INFOCOM'14）：用多个天线接收的相位差算**距离差**→以天线对为焦点画**双曲线**→多条双曲线**交点**即标签位置。**克服了相位周期性和硬件相位偏移问题**，精度较好。
- **b) 信号到达角 AoA 法**（RF-IDraw, SIGCOMM'14）：把双曲线法**简化为用渐近线**估位置。部署8个天线（1~4相距8λ，<5,6>和<7,8>间距λ/2），用各组 AoA 模型的**重叠区域**定位。受硬件固有相位偏差影响，**绝对定位精度一般，但追踪运动轨迹精度极高**（虚拟空中触屏）。
- **c) 相位空间分布概率法**：较高精度，3 天线。
- **d) 相位时空特征法**（NSDI'15）：**移动天线**扫描一组标签，得各标签连续相位值（一串称**相位轮廓**），分析相位轮廓的时空动态变化，估算标签在空间中的**相对顺序**。

#### （3）基于其他特征

- **a) 多径效应轮廓法**（SIGCOMM'13）：目标标签与**邻近**参考标签有**相似的多径效应轮廓**，与较远的不同——据此定位（可在多径/非视距 NLOS 下工作）。
- **b) 信号传输时间法**：精度高、耗时高、3 天线。

### 4. 定位技术小结对比表（11.6，必背）

|类别|方法|精度|耗时|天线数|需参考标签|商用阅读器|
|---|---|---|---|---|---|---|
|信号强度|RSSI空间指纹|低|高|4|是|是|
|信号强度|信号传播模型|低|低|8|是|是|
|信号强度|信号扰动|高|高|1|是|是|
|相位|相位差双曲线|中|中|4|否|是|
|相位|信号到达角|较高|中|8|否|是|
|相位|相位空间分布概率|较高|中|3|否|是|
|相位|相位时空特征|—|高|1(移动)|否|是|
|其他|多径效应轮廓|中|高|1(移动)|是|否|
|其他|信号传输时间|高|高|3|否|否|

> 记忆规律：**相位类普遍不需要参考标签、精度中上**；**信号强度类大多需参考标签、精度偏低**；高精度往往伴随高耗时。

## 第二部分：动作识别技术（以 RFID 为例）

### 1. 传统移动行为感知的局限（12.2.1）

|识别机制|优点|缺点|
|---|---|---|
|**基于计算机视觉**|理想环境感知准确、直观、范围广|易侵犯隐私、受光线影响、计算量大|
|**基于可穿戴设备**|针对性强、不易引起隐私问题|功能单一、有源设备、拓展性不强|

→ 引出**基于无线信号（RFID）的感知**作为新思路。

### 2. 基于无线信号的两种感知机制（12.2.2）

|机制|优点|缺点|
|---|---|---|
|**信号模型**|拓展性强、无需训练数据|只能感知简单行为、难区分多目标|
|**模式匹配**|能感知复杂行为|需大量训练数据、难拓展、难区分多目标|

这两条思路贯穿后面的绑定式与非绑定式感知。

### 3. 感知方式的总体划分

按"标签是否贴在被感知对象上"分为：

- **绑定式感知**：标签贴在物体/人身上，标签随动作运动；
- **非绑定式感知**：标签不贴身，靠**人体对周围标签信号的影响/遮挡/反射**来感知（设备无关感知）；
- **混合式感知**：兼用两者。

### 4. 基于 RFID 的绑定式感知（12.3）

四个小节：①基于标签**能量耦合**变化；②基于**相位模型**；③基于**模式匹配**（用 PCA 学习动作信号变化、用机器学习感知，典型系统 **RF-Glove**：放大/缩小/左旋/右旋/弹开手势）；④案例分析。

### 5. 基于 RFID 的非绑定式感知（12.4）

机制对应前面两条思路：

- **电感耦合**（双标签）；
- **信号模型**（如 TACT：利用人体对信号连续性的影响、反射，跟踪信号变化趋势感知行为）；
- **模式匹配**：识别八类动作——站立/坐下/举手/落手/行走/跌倒/旋转/坐起；
- **案例 RF-finger**：基于 RFID 标签阵列的**细粒度手指运动识别**。面临挑战：**多径效应的影响、漏读现象严重**。

### 6. 动作识别小结对比表（12.6，必背）

| 感知方式     | 感知技术 | 优势              | 劣势                    |
| -------- | ---- | --------------- | --------------------- |
| **绑定式**  | 能量耦合 | 角度敏感、通用性强       | 易受环境影响，需线性极化天线与标签配合   |
| 绑定式      | 相位模型 | 高精度完成定位追踪       | 适用平面感知，需相位信息、需多天线     |
| 绑定式      | 模式匹配 | 能解决大部分识别问题、简单直接 | 需收集大量训练数据、可拓展性弱       |
| **非绑定式** | 电感耦合 | 高精度、成本低、理论与实践结合 | 需双标签配合、检测区域有限、只能跟单个对象 |
| 非绑定式     | 信号模型 | 适用范围广、面向多群体、便捷  | 对环境要求高、只能跟单对象、方向依赖性高  |
| 非绑定式     | 模式匹配 | 覆盖广、稳定性强、无需大量训练 | 环境适应性弱，新环境需重训模型       |
| **混合式**  | 信号模型 | 感知粒度细、感知能力强     | 抗干扰弱、部署要求高            |

## 一、无线传感器网络（WSN）

- **无线网络分类**：有基础设施网 / 无基础设施网（自组网）。
- **WSN 类比**：现代信息技术 = 传感器（感官）+ 计算机（大脑）+ 通信（神经）。
- **节点三大限制条件**：①电源能量；②通信能力；③计算和存储能力。
- **六大组网特点**：①自组织性；②**以数据为中心**；③应用相关性；④动态性；⑤网络规模大；⑥可靠性。

## 二、WSN 节点定位

**含义**：自组织网络通过特定方法提供节点位置信息（无位置的监测数据往往无意义）。两大类方法：

### 1. 基于测距（Range-based）

|方法|代表系统|原理|
|---|---|---|
|**ToA**（到达时间）|GPS|由信号传播时间×速度算距离|
|**TDoA**（到达时间差）|Cricket、AHLoS|两种信号到达时间差测距|
|**AoA**（到达角）|APS|测信号到达角度|
|**RSSI**（信号强度）|RADAR|强度随距离衰减反推距离|

- **GPS 服务**：SPS（民用，精度~100cm）、PPS（授权军用，精度~1cm）。
- **RSSI 对数距离路径损耗模型（要记）**：$RSSI = A - 10,n\lg(d)$（A为参考强度，n为路径损耗因子，d为距离）。

### 2. 无需测距（Range-free）

- **DV-Hop**（2003）：按距离矢量路由原理全网广播**跳数与位置**，解决低锚点密度问题；适合少量定位良好的锚点+规则静态分布，节点移动或分布不均时效果差。
- **Amorphous**：同属跳数类技术。
- **Centroid 质心法**（2000）：取所听到的所有锚点位置的**中心**作为估计。
- **APIT**（2003）：用三角形区域判断，依赖**高密度锚点**（长传输范围）。

## 三、计算机网络基础

- **三网**：电信网络、有线电视网络、计算机网络（**计算机网络发展最快、起核心作用**）。
- **因特网两大块**：**边缘部分**（所有主机，用户直接用来通信和资源共享）+ **核心部分**（大量网络+路由器，提供连通性与交换，**路由器是分组交换的关键构件**）。
- **边缘两种通信方式**：**C/S（客户-服务器）**——请求方/提供方关系；**P2P（对等）**——每台主机既是客户又是服务器（本质仍是 C/S）。

## 四、三种交换技术（对比，考点）

| |电路交换|报文交换|分组交换|
|---|---|---|---|
|过程|建立连接→传送→释放|存储转发|存储转发|
|传送单位|比特流直达终点|整个报文|分组（报文切片）|
|特点|独占线路、时延小但利用率低|无需建连、时延大|兼顾，主流|

> N 部电话两两相连需 N(N−1)/2 对电线（与平方成正比），故需交换机。

## 五、网络性能指标（核心计算点）

- **速率**：数据率/比特率，单位 b/s（注意计算机界 K=2¹⁰=1024）。
- **带宽**：数字信道能传的最高数据率（b/s）。
- **吞吐量**：单位时间通过网络的实际数据量，受带宽限制。
- **四种时延（必考公式）**：
    - **发送时延（传输时延）** = 数据块长度(bit) / 信道带宽(bit/s)
    - **传播时延** = 信道长度(m) / 信号传播速率(m/s)
    - **处理时延**、**排队时延**（取决于当时通信量）
    - **总时延 = 发送 + 传播 + 处理 + 排队**
- **易错点**：提高带宽只减小**发送时延**，不改变比特在链路上的**传播速率**。
- **时延带宽积** = 传播时延 × 带宽（又称"以比特为单位的链路长度"）。
- **利用率**：信道/网络利用率并非越高越好。时延与利用率关系 $D = \dfrac{D_0}{1-U}$（U→1 时延急剧增大）。

## 六、体系结构

- 分层好处：各层独立、灵活、可分割、易实现维护、促进标准化。
- **五层协议体系结构**（自上而下）：**应用层 → 运输层 → 网络层 → 数据链路层 → 物理层**。TCP/IP 为四层（应用/运输/网际/网络接口）。

## 七、物理层（核心计算点）

- **三种基本调制**：调幅 AM（振幅变）、调频 FM（频率变）、调相 PM（相位变）；**QAM 正交振幅调制**（相位×振幅组合，如 16-QAM 用 4bit 编一个码元）。
- **奈奎斯特准则（1924）**：理想条件下为避免**码间串扰**，码元传输速率有上限；信道频带越宽可用更高码元速率。**采样定理（奈奎斯特定理）**：采样频率 fs > 2·fmax（实际取 2.56~4 倍）。
- **★ 香农公式**（带宽受限+高斯白噪声信道的极限无差错速率）：

$$C = W\log_2!\Big(1+\frac{S}{N}\Big)\ \text{b/s}$$

（W 带宽 Hz，S 信号功率，N 噪声功率）。带宽或信噪比越大极限速率越高；只要速率低于 C 就一定能找到无差错传输方法；实际速率比 C 低不少。

## 八、信道复用（核心计算点）

- **FDM 频分复用**：用户始终占用不同频带（同时不同频）。
- **TDM 时分复用**：用户周期性占用固定时隙（不同时同频），又称等时信号。
- **统计时分复用**。
- **★ CDM/CDMA 码分复用**：各用户用特殊**码片序列（chip sequence）**，互不干扰、抗干扰强、频谱似白噪声。规则：
    - 每比特划分为 m 个码片；发"1"发本站码片序列，发"0"发其反码（用 −1 表 0、+1 表 1）；
    - 各站码片序列必须**两两正交**（规格化内积为 0）：$S\cdot T=\frac1m\sum S_iT_i=0$；
    - 与自己的规格化内积 $S\cdot S=1$，与自身反码 $S\cdot \bar S=-1$。
    - **解码计算**：收到合成序列 S，与各站码片做规格化内积——结果 +1 表该站发"1"，−1 表发"0"，0 表该站未发。
        
        > 例：收到 (−1 +1 −3 +1 −1 −3 +1 +1)，与 A/B/C/D 内积分别 =1/−1/0/1 → A、D 发"1"，B 发"0"，C 未发。**这是必考计算题型。**
        

## 九、差错检测

- **误码率 BER** = 错误比特 / 总比特，与信噪比强相关。
- **CRC 循环冗余检验**：数据后添 n 位冗余码。**注意**：CRC 只能做到"**无差错接受**"（接受的帧极大概率无错，有错则丢弃），要实现"**可靠传输**"（发什么收什么）还须加**确认与重传**机制。

## 十、局域网与介质访问

- 拓扑：星形、总线、环形、树形。
- **隐藏终端问题**：节点间**无法互相监听**，同时传输导致冲突；**单 AP** 时即可能发生。
- **暴露终端问题**：节点间**能互相监听**，本可同时传输却不传输，造成浪费；**多 AP** 时才可能发生。
- **CSMA/CA（载波侦听多路访问/碰撞避免）**：先听信道——空闲则占用并标忙；忙则用**随机退避算法**等待后再听。多终端退避时，**退避时间最短者竞争获胜**。

## 十一、IP 地址（核心计算点）

- IP 地址：全球唯一的 **32 位**标识符，由 ICANN 分配；记法 IP::={网络号 net-id, 主机号 host-id}。**点分十进制**：每 8 位转十进制（如 11000000.10101000.00000001.00000011 = 192.168.1.3）。
- **五类地址（按前缀位）**：

|类|前缀|net-id 长|最大网络数|每网最大主机数|
|---|---|---|---|---|
|A|0|1字节|126 (2⁷−2)|16,777,214|
|B|10|2字节|16,383 (2¹⁴−1)|65,534|
|C|110|3字节|2,097,151 (2²¹−1)|254|
|D|1110|—|多播地址|—|
|E|1111|—|保留|—|

- **私有地址段（要记）**：A 类 10.0.0.0–10.255.255.255；B 类 172.16.0.0–172.31.255.255；C 类 192.168.0.0–192.168.255.255。
- **★ 子网划分计算（必考）**，步骤：
    
    1. IP 与子网掩码转二进制；
    2. **按位与**得**网络地址**；
    3. 主机位**全置 1**得**广播地址**；
    4. 地址范围 = 网络地址+1 ～ 广播地址−1；
    5. 可用主机数 = **2^(主机位数) − 2**（去掉网络地址与广播地址）。
    
    - 借位规则：**2^(借用主机位) ≥ 子网数**。例：划 4 个子网借 2 位，掩码 .0→.192，每子网 2⁶−2=62 台。
    - 变长子网（VLSM）：按各单位所需主机数倒推主机位（如需 500 个→2⁹，9 位主机位）。

## 十二、网络层路由

- **默认路由**：减少路由表项与查表时间，适合只有少量对外连接的小网络。
- **★ 距离向量算法（RIP）**：路由器与相邻路由器周期交换**整张路由表**。收到相邻路由器 X 的报文后：把下一跳改为 X、距离 +1；新目的网络则加入；同下一跳则替换；距离更小则更新；3 分钟未更新则置距离=16（**16 表示不可达**，最大可用距离 15）。
- **核心现象**："**好消息传播得快，坏消息传播得慢**"——网络故障后两路由器距离会一直累加直到都到 16 才确认不可达（计数到无穷问题）。优点：实现简单、开销小；缺点：限制网络规模、收敛慢、交换整表开销随规模增大。

## 十三、运输层（核心计算点）

- **TCP**（面向连接）：逻辑信道相当于**全双工可靠**信道；**UDP**（无连接）：不可靠信道。运输层重要功能是**复用与分用**（不同进程经不同端口）。
- **★ TCP 拥塞控制**（会画图、会算 cwnd）：发送方维护拥塞窗口 cwnd，发送窗口取 cwnd 与接收窗口 rwnd 的最小值。
    - **慢开始**：cwnd 初值=1（1个MSS），每收到一个新确认 cwnd+1，**每经一个传输轮次（RTT）cwnd 翻倍**（指数增长）；
    - **拥塞避免**：当 cwnd ≥ **ssthresh（慢开始门限）** 时改用，每个 RTT 仅 **+1**（线性"加法增大"）；
    - **出现拥塞（超时）时**：ssthresh = 出现拥塞时 cwnd 的**一半**（不小于2），cwnd **重置为 1**，重新执行慢开始（"乘法减小"）。
    - 记忆：慢开始指数涨 → 到门限转线性"加法增大" → 拥塞则"乘法减小"并回到 cwnd=1。

# 第五章 编码与校验码

围绕一个核心问题：**如何在数据中加入冗余，使传输/存储出错时能被发现甚至纠正**。按"能力从弱到强"展开：**奇偶校验（检错）→ 海明码（纠错）→ CRC（强检错）**，外加两类常用编码（**格雷码、身份证校验**）。本章几乎全是计算题，务必动手练。

## 预备概念：码距与检错纠错能力

- **码距（汉明距离）**：两个合法码字之间不同比特的个数；一种编码的**最小码距 d** 决定其能力。
- **能力关系（要记）**：检出 e 位错需 **d ≥ e+1**；纠正 t 位错需 **d ≥ 2t+1**。
- 加校验位的本质就是**增大最小码距**（如奇偶校验把最小码距从 1 提到 2）。

---

## 一、奇偶校验（Parity Check）

最简单的校验码，在有效信息后加 **1 位校验位**，**码距 = 2**。

- **奇校验**：整个校验码（信息+校验位）中"1"的个数为**奇数**；
- **偶校验**："1"的个数为**偶数**。
- **能力**：可检出 **1 位（或奇数位）错误**，但**不能定位**出错位置，**也不能检出偶数位错误**。
- 例（偶校验，最高位为校验位）：0000→00000，0001→**1**0001，0011→00011……（补校验位使总"1"数为偶）。

---

## 二、海明码（Hamming Code，核心计算点）

能**定位并纠正 1 位错误**的经典纠错码，思想是用多个奇偶校验位"交叉覆盖"数据位。

**编码规则**：

1. **校验位放在 2 的幂位置**：P₁、P₂、P₄、P₈…（即位号 1、2、4、8…），其余位放数据位。例 k=4 时总长 8：排列为 `P4 D4 D3 D2 P3 D1 P2 P1`（位号 H8…H1）。
2. **每个校验位覆盖哪些位**：Pᵢ 校验**所有"位号二进制展开中含该位"**的位置——
    - P₁ 管位号 1,3,5,7…（位号二进制最低位=1）→ 即 D1、D2、D4；
    - P₂ 管位号 2,3,6,7…（次低位=1）→ D1、D3、D4；
    - P₃(P4位) 管位号 4,5,6,7（第3位=1）→ D2、D3、D4。
3. 各 Pᵢ 取值使所覆盖位（含自身）满足**偶（或奇）校验**。

**校验位数 r 的确定**：纠正 1 位错误需满足

$$2^r \ge k+r+1$$

例 k=8 → r=4（总长 12，正好对应 `计算题` 第3题）。

**检错/纠错过程**：接收端按三组（或更多）校验式算出 **S₃S₂S₁**（校验子 syndrome）：

- S₃S₂S₁ = **000** → 无错；
- S₃S₂S₁ ≠ 000 → 其二进制值**正好是出错位的位号**，把该位取反即纠正。
    
    > 对应表：001→H1、010→H2、011→H3、100→H4、101→H5、110→H6、111→H7。
    

**升级到"检2纠1"（SEC-DED）**：再加一个**总校验位 P₄(S₄)** 做全局奇偶校验：

- S₁S₂S₃≠000 且 S₄=1 → 1 位错（可纠）；
- S₁S₂S₃≠000 且 S₄=0 → 2 位错（仅检出，不可纠）。
- 此时校验位数对应表（k→r）：1–4→4、5–11→5、12–26→6、27–57→7、58–120→8。

---

## 三、循环冗余校验码（CRC，核心计算点）

纠错能力强、硬件代价小，广泛用于**串行传输检错**。称 **(n, k) 码**：k 位信息位后拼接 **r 位校验位**，总长 **n = k + r**。

**核心工具：生成多项式 G(x)**（r+1 位，最高位为 1）与**模 2 运算**（加减都是**异或 XOR**，无进位借位）。

**发送方流程**：

1. 数据 D（d 位）后**补 r 个 0**得 D·2ʳ；
2. 用 G **模 2 除** D·2ʳ，得 **r 位余数 R**；
3. 发送 **DR**（即 D 后接 R，共 d+r 位），它能被 G 模 2 整除。

**接收方流程**：用 G 去除收到的 DR——**余数为 0** 则传输正确（去掉尾部 r 位得 D）；**余数非 0** 则发生差错。

**模 2 除法规则**：上一次部分余数最高位为 1 则上商 1（做模 2 减/XOR），否则上商 0；每步去掉部分余数最高位的 0；当部分余数位数少于除数时即为最终余数。

**★ 算例（对照 `计算题` 第4题）**：D=`11010110`，G(x)=x⁴+x³+1 → 二进制除数 **`11001`**（5 位，故 r=4）。

- D 后补 4 个 0：`110101100000`，模 2 除以 `11001`：

```
110101100000  ⊕ 11001 →
000111100000  ⊕  11001(右移到首个1) →
000001110000  ⊕   11001 →
000000010100  ⊕    11001 →
000000001101  ← 末4位即余数
```

- 余数 **R = 1101**，发送帧 = `11010110 1101`。接收端用 `11001` 去除该帧，余数为 0 即无错。

> 注意 CRC 与 IP/信道复用章的呼应：CRC 只能"**无差错接受**"，要"可靠传输"还需**确认+重传**。

## 四、格雷码（Gray Code）

**特点**：相邻两个码字仅 **1 位**不同（反射码），可避免计数/编码跳变时的多位同时翻转误差。

**二进制 → 格雷码（编码）**：最高位不变，其余位为相邻两位异或：

$$G_i = B_i \oplus B_{i+1}\quad(n-1\ge i\ge 0,\ B_n\text{视为}0)$$

例：B=`1011` → G：G₃=1，G₂=1⊕0=1，G₁=0⊕1=1，G₀=1⊕1=0 → G=`1110`。

**格雷码 → 二进制（解码）**：最高位不变，其余位 = 当前格雷码位 ⊕ 已求出的高一位二进制位（$B_i=G_i\oplus B_{i+1}$）。

**递归生成（反射构造）**：(n+1) 位格雷码 = 前半 = n 位码顺序加前缀 0；后半 = n 位码**逆序**加前缀 1。此外还有余三格雷码、空六码、跳六码等多种形式。

## 五、应用：身份证校验码

18 位 = **地址码(6) + 出生日期码(8) + 顺序码(3, 奇男偶女) + 校验码(1)**。校验码由**前 17 位加权求和模 11** 得到，是一维校验思想的实际应用。

---

**编码与校验码**是计算密度最高的一章，复习就是**反复练算**：

> **必练算法**：CRC 模 2 除法求 R 与验错 ＞ 海明码编码（校验位定位+求值）与纠错（校验子定位）＞ 格雷码↔二进制互换 ＞ 奇偶校验 **必记结论**：码距与检错纠错能力（检 e 需 d≥e+1，纠 t 需 d≥2t+1）、海明码 2ʳ≥k+r+1、奇偶校验码距2（检奇数位、不能定位、不能检偶数位）

## 四、计算题套路（对照 `计算题.pdf`，必练）

### 题1：VLSM 变长子网划分

C 类 `203.100.50.0`，分 A(60)/B(30)/C(10) 主机。**套路：按主机数从大到小，每子网取 2ʰ−2≥需求 的最小 h**：

|子网|需求|主机位 h|前缀|子网掩码|网络地址|可用范围|广播|
|---|---|---|---|---|---|---|---|
|A|60|6 (62)|/26|255.255.255.192|.0|.1–.62|.63|
|B|30|5 (30)|/27|255.255.255.224|.64|.65–.94|.95|
|C|10|4 (14)|/28|255.255.255.240|.96|.97–.110|.111|

### 题2：等长子网划分

`192.168.88.0/22`，每子网恰好 **62 可用 IP**。

- 62 = 2ʰ−2 → **h=6 → 新掩码 /26（255.255.255.192）**；
- 借位 = 26−22 = 4 → **2⁴ = 16 个子网**；
- 第一个子网：网络地址 `192.168.88.0`，广播 `192.168.88.63`。

### 题3：海明码（偶校验，纠1位）

8 位数据 → 12 位码字。**套路**：

1. **校验位放 1、2、4、8 位**；数据位放 3、5、6、7、9、10、11、12 位（共8个）。
2. 各校验位覆盖"**位号二进制中该位为1**"的所有位：
    - P₁(位1)：管 1,3,5,7,9,11
    - P₂(位2)：管 2,3,6,7,10,11
    - P₄(位4)：管 4,5,6,7,12
    - P₈(位8)：管 8,9,10,11,12
3. 按**偶校验**令每组(含自身)的"1"个数为偶 → 解出 P₁P₂P₄P₈，填回得 12 位码字。
4. **纠错**：收到码字后，重算每组偶校验得校验子 **S₈S₄S₂S₁**——若全 0 无错；非 0 时其十进制值**就是出错位号**，把该位取反，再抽出数据位即恢复原数据。

### 题4：CRC（模2除法）

D=`11010110`，G(x)=x⁴+x³+1 → 除数 **`11001`**（r=4）。**套路**：D 后补 4 个 0，模 2 除（XOR，无借位）：

```
110101100000 ⊕11001 → 000111100000 ⊕11001 → 000001110000
            ⊕11001 → 000000010100 ⊕11001 → 000000001101
```

- 余数 **R = 1101** → 发送帧 = `11010110 1101`。
- **验错**：接收端用 `11001` 去除收到帧，余数为 0 则无错，非 0 则有错。若收到 `11010110 1010`（R′=1010≠1101），相除余数非 0 → **检出传输错误**。

# 第六章 边缘计算

### 1. 为什么需要边缘计算（背景与动机）

物联网终端爆炸式增长——预计 **2025 年超千亿终端联网、数据量达 300ZB**。若沿用传统"全部上云"的方式，云计算中心会撞上五道墙：**网络时延高、海量设备接入、海量数据处理难、带宽不够、功耗过高**。边缘计算正是为破解这些痛点而生。

### 2. 什么是边缘计算（定义 + 直觉）

**定义**：在**靠近物或数据源头的网络边缘侧**，融合**网络、计算、存储、应用**核心能力的**分布式开放平台**，就近提供边缘智能服务。一句话——把数据**在产生地附近就地分析**，无需都传到云端。

**图书馆比喻（好记）**：云计算 = 所有问题都交给图书馆管理员查（准确但要等）；边缘计算 = 自己家里能查的就地查，查不到才求助图书馆（响应快、传输少）。

### 3. 边缘计算架构（四层，核心考点）

数据"从下往上"逐层处理，能就地解决的绝不上送：

|层|角色|关键点|
|---|---|---|
|**终端节点**|各类 IoT 设备（传感器、RFID、摄像头、手机）|只负责**感知/采集上报**，不需要计算能力|
|**边缘计算节点**|网络边缘侧的计算/存储单元|就地处理，实现**基础服务响应**|
|**网络节点**|传输通道|把边缘处理后的**有用数据**上传云端|
|**云计算节点**|中心云|**永久存储**、边缘处理不了的**复杂/全局任务**、动态调整边缘的部署策略与算法|

> 实现上常依赖：边缘设备（网关/智能摄像头/IoT）+ 边缘服务器（**MEC 多接入边缘计算**）+ 云端**协同**。

**两个操作方向**：

- **上游边缘计算**（面向数据源）：数据捕获 → 实时处理与决策（筛选/聚合/初分析，关键指令就地执行）→ 优化传输（减少对中心依赖）→ 多层架构（微数据中心/边缘服务器/设备内微处理器，可临时存储）。
- **下游边缘计算**（面向用户交付）：**CDN 内容分发**（就近缓存提速）、云边集成（多地边缘节点减少往返）、**移动性支持**（借 5G 支撑 AR/无人机/远程医疗）。

### 4. 边缘计算五类主要算法（★★ 最核心考点）

这一节是本章重点，也是把后面几章串起来的"钩子"：

**（1）数据处理与预处理**——在上云前削减冗余：

- **数据过滤**：只传重要数据（如只上传有运动的帧，而非每一帧）；
- **数据压缩**：如 JPEG 图像压缩、高效压缩算法省带宽；
- **数据聚合**：本地先算汇总（温度的均值/最大/最小）再上传。

**（2）模型剪枝与量化**（★ 直接通向"轻量化机器学习"章）：深度模型往往太大，边缘跑不动，于是——

- **模型剪枝（Pruning）**：移除冗余的神经元/连接，**保精度的同时减计算量**；
- **模型量化（Quantization）**：把浮点数转低精度整数（如 **FP32 → INT8**），减存储与计算开销。

**（3）任务分配与调度**——决定"在哪算"：

- **动态任务调度**：按当前带宽与设备负载分配（如车联网中某车算力吃紧，就把部分任务转移到邻车或路边边缘服务器）；
- **卸载策略（Offloading）**：决定任务**本地算还是上云**，常用**贪心算法、强化学习**。课件给的例子：按任务轻/中/重三档，结合边缘设备当前算力用**贪心**决定卸载。

**（4）分布式协作**（★ 直接通向"联邦学习""区块链"章）：

- **联邦学习**：多边缘设备**不上传原始数据**地共训一个模型，保护隐私；
- **共识算法**：如区块链中边缘节点间达成共识，保证数据一致。

**（5）边缘 AI 推理**——要快、要实时：

- **轻量化神经网络**：**MobileNet、Tiny-YOLO**（专为移动/嵌入式设计）；
- **混合精度（Mixed Precision）**：训练/推理中混用 FP16 与 FP32 提速。
- 例子：无人机用 **Tiny-YOLO** 在飞行中实时检测障碍物，不依赖云端。

> 记忆主线：这五类算法 = **"减数据（1）+ 减模型（2、5）+ 调度算（3）+ 协同算（4）"**，本质都在回答"算力/带宽不够时怎么办"。

### 5. 典型应用（了解即可）

智慧城市（边缘实时处理交通流优化信号）、工业自动化（产线异常即时停机）、远程医疗（救护车上解读心电图、到院前给建议）、智能家居（智能门锁本地人脸识别，免等云端）。

### 6. 五大优势 vs 三大挑战（易考对比）

|优势|挑战|
|---|---|
|**低延迟**（自动驾驶/VR）|**资源受限**（算力/内存/电量有限，需优化算法）|
|**高带宽利用率**（只传结果）|**数据隐私**（边缘需在保护隐私前提下高效算）|
|**增强隐私与安全**（敏感数据本地处理）|**安全性**（边缘设备易受攻击，需可靠安全算法）|
|**离线可用**（断网仍工作，如偏远农业）||
|**可扩展与稳定**（分布式部署，弹性扩容）||

# 第七章 轻量化机器学习

### 1. 为什么要轻量化（必要性）

高性能模型往往**计算量大、存储需求高**，难以在资源受限设备（移动终端、嵌入式、IoT）上跑。轻量化就是**在保住性能的前提下，降低计算复杂度与资源消耗**。四个现实困境（与边缘计算的挑战呼应）：

- **计算资源有限**：手机/手表/无人机受限于算力、内存、电池；
- **低延迟需求**：自动驾驶、VR、实时翻译要求推理快；
- **能耗问题**：大模型计算耗电，缩短续航；
- **带宽与存储限制**：卫星通信、远程监控下，小模型才好传好部署。

**六个设计目标**：① 减参数量(param)与计算复杂度(FLOPs)；② 降存储/显存；③ 提推理速度；④ 减能耗；⑤ 保性能；⑥ 适应多样场景。

### 2. 模型评估：参数量与计算复杂度（★ 必考计算）

两个核心指标：

- **参数量 param**：需训练并存储的权重数量，衡量模型**规模**；
- **计算复杂度 FLOPs**：推理时的**浮点运算次数**，衡量计算开销。

**全连接层**（nin 输入、nout 输出）：

$$\text{params}=n_{in}\times n_{out}+n_{out}\qquad \text{FLOPs}=n_{in}\times n_{out}\times 2$$

- 后一项 +nout 是**偏置项**；FLOPs 乘 2 是因为每个连接含**一次乘法 + 一次加法**。
- 例（256→128）：params = 256×128+128 = **32896**；FLOPs = 256×128×2 = **65536**。
- 课件思考题"为何有的模型没偏置项"——若该层后接 **BN（批归一化）**，BN 自带偏移会吸收偏置，bias 变冗余可省去。

**卷积层**（核 k×k、输入通道 cin、输出通道 cout、输出特征图 H×W）：

$$\text{params}=k\times k\times c_{in}\times c_{out}+c_{out}\qquad \text{FLOPs}=H\times W\times c_{in}\times c_{out}\times k\times k\times 2$$

**其他模块**：池化层（**参数 0**，只做窗口内取最大/平均，复杂度低）、激活层 ReLU/sigmoid/tanh（**参数 0**，提供非线性，代价是模型更像"灰盒"难解释）、归一化层 BN/LN（**参数很少**，少量可训练的缩放与偏移）。

### 3. 模型压缩与优化四大技术（★★ 核心）

#### （1）模型剪枝（Pruning）

**动机**：研究发现深度模型中**只有一部分权重起关键作用，其余冗余**——剪掉它们即可压缩。

- **两类**：**非结构化剪枝**（随机剪独立权重/神经元连接，压缩率高但稀疏不规则、难加速）、**结构化剪枝**（按 filter/channel/layer 整块剪，规整、易加速）。
- **三种流程**：① 训练→剪枝→微调；② 训练中剪枝→微调；③ 剪枝→从头训练。

#### （2）模型量化（Quantization）

把高精度浮点映射为低精度定点（如 FP32→INT8），减存储与计算。

- **线性量化**有**对称/非对称**两种映射，转换公式：

$$r = S,(q - Z)$$

（r 浮点值、q 量化整数、**S 缩放因子 Scale、Z 零点 Zero-Point**）。调 S、Z 即把浮点映射到目标整数范围。

- **MinMax 求解**：用浮点数据的 Rmax/Rmin 与定点范围 Qmax/Qmin（如 127/−128 或 255/0）确定 S、Z。
- **三种量化方法**：
    - **QAT 量化感知训练**：训练时就让模型"感知"量化误差，通过 finetune 降低精度损失（精度最好）；
    - **PTQ Dynamic 动态后训练量化**：仅把特定算子权重 FP32→INT8/16（最简单）；
    - **PTQ Static 静态后训练量化**：用**少量无标签校准数据**+ KL 散度等算量化比例因子。

#### （3）知识蒸馏（Knowledge Distillation）

用大"教师模型"教小"学生模型"。

- **四类知识**：response-based（学生直接模仿教师**最终预测**）、feature-based（关联中间层**特征激活**）、relation-based（学习层间/样本间**关系**）、architecture-based。
- **三种方式**：Offline（教师先训好再教）、Online（师生共同学）、Self-Distillation（自学）。
- **★ Hinton 经典法**：用教师输出的**类别概率作 soft target** 训学生；关键技巧 **Softmax with Temperature**：

$$q_i=\frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$$

温度 **T 越大，softmax 分布越平缓、信息熵越大**（暴露更多"类间相似性"知识）。流程：① 训教师；② 高温 T 产生 soft target；③ 用 {soft target,T} 与 {hard target} 共同训学生；④ **推理时令 T=1**。

#### （4）低秩分解

把权重矩阵分解为**低秩近似**，或层间**参数共享**，降存储与计算（Transformer 中常用）。

### 4. 典型轻量化模型结构（识记代表创新）

|模型|核心思想|
|---|---|
|**SqueezeNet**|**Fire 模块**（squeeze 1×1 降维 + expand 1×1/3×3），少参数达 AlexNet 精度|
|**ShuffleNet**|**Channel Shuffle**（分组卷积后打乱通道，兼顾低算力与信息流通）|
|**MobileNet**|**深度可分离卷积**（depthwise + pointwise，大幅降 FLOPs，移动端代表）|
|**EfficientNet**|**MBConv** + **复合缩放**（统一缩放深度/宽度/分辨率，效率最优）|

### 5. 轻量化的应用

**（1）大模型轻量化**：

- **BERT 系**：**DistilBERT**（蒸馏、层数减半、保留约 **97%** 性能、提速）、**TinyBERT**（多级蒸馏：层间+词向量+注意力）、**MobileBERT**（瓶颈线性层+逐层蒸馏，结构更深更窄）、**ALBERT**（参数共享 + 词嵌入因式分解）。
- **GPT 系**：GPT-Neo（开源、125M/1.3B/2.7B 多规模）、GPT-J（约 6B，GPT-3 高效替代）、GPT-2 Small（约 117M，边缘推理）、GPT-3 Ada/Babbage/Curie（"同架构多精度"按需选型）。

**（2）片上训练 On-Device Training**：在手机/手表/IoT 设备**本地**训练或微调，换取**数据本地化、隐私保护、低延迟、个性化**。三大优化方向：模型结构压缩 / 算法层优化 / 硬件协同。四种策略：

- **增量训练与微调**（只更新高层/分类头，冻结底层，省反向传播）；
- **低秩分解与参数共享**；
- **混合精度训练**（FP16 算前向与梯度、FP32 累积权重，兼顾速度与稳定）；
- **自适应优化器**（AdamW/LAMB/Lion，降超参敏感、提鲁棒）。
- 主流平台：Apple Core ML + Neural Engine、Google TensorFlow Lite + EdgeTPU、Meta PyTorch Mobile。

**（3）具身智能**：轻量化模型部署到机器人等实体，实现端侧实时智能。

# 第七章 大模型

### 1. 定义与特点

**大模型（LLM, Large Language Model）**：参数规模达**数亿乃至数千亿**的深度学习模型（如 **GPT-3 达 1750 亿参数**）。三大特点：

- **参数规模庞大**：靠海量数据捕捉复杂语言规律；
- **数据需求量大**：训练数据涵盖网页/书籍/代码等多源信息，规模达 TB 级；
- **任务泛化能力强**：预训练学通用知识后，可适配翻译、问答、创作等多样任务。

### 2. 发展四阶段（识记）

> **1.0 传统机器学习**（SVM、决策树）→ **2.0 深度学习**（CNN、RNN）→ **3.0 预训练模型**（BERT、GPT）→ **4.0 多模态模型**（OpenAI CLIP、DeepMind Gato）

### 3. 核心原理：Transformer 与自注意力

大模型普遍采用 **Transformer 架构**（Google 2017《Attention is all you need》），核心是**自注意力机制 Self-Attention**——通过 **Q(query)、K(key)、V(value)** 三个矩阵动态衡量序列中每个词的重要性，捕捉**长距离依赖**。例："猫吃鱼"中"吃"会同时关注"猫"和"鱼"。训练目标本质是**用前文 token 预测下一个 token**。

### 4. 生成式 AI 训练三阶段（★ 核心考点，"厨师"比喻好记）

|阶段|比喻|做什么|方法|
|---|---|---|---|
|**① 预训练 Pre-training**|厨师上烹饪学校打基础|海量文本学语法、常识、语言结构|**自监督**：掩码语言模型 MLM / 自回归预测下一词|
|**② 有监督微调 SFT**|师傅带徒弟练经典菜|用人工标注的高质量"问题—标准答案"示例，让回答符合人类期望|**监督学习** + 提示(prompt)学习 + 指令(instruction)微调|
|**③ 人类价值对齐 RLHF**|按顾客反馈改菜品|让回答更符合人类偏好、避免有害无意义输出|收集**人类偏好排序** → 训**奖励模型** → 用 **PPO** 强化学习优化|

> 记忆主线：**预训练学知识 → SFT 学规范 → RLHF 学偏好**；一句话——"打基本功 → 说人话做人事 → 与人类价值对齐"。

### 5. 扩展定律 Scaling Law

**"数据是燃料、模型是引擎、算力是加速器"**：随着**模型规模、训练数据、计算资源**的增加，模型性能会**可预测地**显著提升，这就是**扩展定律（Scaling Law）**。课件引述两个观点佐证"算力为王"：

- **黄氏定律（黄仁勋）**：在计算架构改进推动下，AI 芯片性能**每年提升 1 倍**，超过摩尔定律；
- **《苦涩的教训》（Rich Sutton, 2019）**：纵观 70 年 AI 史，"想办法利用**更大规模算力**总是最高效的手段"。

但堆算力必有天花板——如何破局？引出 DeepSeek。

### 6. DeepSeek：算法与工程的系统级协同创新（★ 本章重点）

**定位**：仍基于 2017 年的 Transformer 架构，**没有颠覆性基础理论创新**，但在**模型算法 + 工程优化**上做了**系统级创新**，在 **2048 块英伟达 H800**（对华低配版 GPU）集群上完成训练，**打破了"大模型必须靠大算力"的预期天花板**。

**DeepSeek-V3 两大关键技术**：

- **MoE 混合专家（稀疏激活）**：共 61 层 Transformer，每层含 **256 个专家 + 1 个共享专家**；基座**总参数 6710 亿**，但**每个 token 仅激活 8 个专家、370 亿参数**。相比稠密模型预训练更快，相同参数量下推理更快。
- **MLA 多头潜在注意力（低秩压缩）**：引入**低秩**思想压缩巨大的注意力矩阵，减少参与运算的参数，在保性能的同时显著降低算存成本，**显存占用降到其他大模型的 5%–13%**。

> 注意它和上一章的呼应：**MoE 稀疏激活、MLA 低秩压缩**本质都是"轻量化"思想（低秩分解、按需激活）用在了超大模型上——大模型与轻量化并非对立，而是殊途同归地追求"算力效率"。

### 7. 未来展望（了解，偏讨论性，低考概率）

课件给出若干前瞻判断（多为观点，复习时知道结论即可）：

- **工程化创新本身就是技术实力**（"物理是深度，工程是规模"）；开源开放推动"由专到通"的发展路径与可信 AI；
- DeepSeek 仍未解决深度学习的**不可解释性、AI 幻觉、黑箱效应**；
- **算力需求不跌反涨**：效率提升反而可能引发 AI 应用爆发，总算力需求指数增长（"杰文斯悖论"式效应）；
- **云计算是第一风口**（助力"模型平权"）；通用大模型创业窗口收窄，转向**垂直化、场景化**；
- **AI 平权**让更多国家参与；**单位智能成本每年约降 10 倍**（Sam Altman）；
- **下一个突破可能在多模态**。

# 第八章 联邦学习

### 1. 定义与核心思想

**联邦学习（Federated Learning, FL）**，又名联合/联盟学习，是一种**分布式机器学习框架**：允许**多个参与方在不共享原始数据的前提下共同训练模型**。原则是**去中心化**——各方用**本地数据**训练，只把**模型更新（梯度或参数）**发给中央服务器，**原始数据始终不出本地**。

> 一句话本质：**"数据不动模型动"**——传的是模型/梯度，不是数据。

### 2. 起源与动机（谷歌 2017.4）

最初为解决 **C 端手机上的模型训练**问题。以**输入法**为例：它需基于用户打字习惯不断更新才会"越来越智能"。

- **过去做法**：把用户行为数据全部上传云端，云端训练更新模型，应用时本地请求云端。
- **两大弊端**：① **隐私**——数据被统一采集到服务器，在严监管下越来越受限；② **实时性**——应用时要网络请求云端，**延迟或断网时模型失效**。
- **解决思路（典型流程）**：数据不出本地 → 本地训练 → 模型参数/梯度**加密上传** → 云端**聚合**（如加权平均）得新参数 → **下发**回本地 → 本地更新模型。即"**分布式模型训练**"。

### 3. 技术挑战

- **数据非独立同分布（non-IID）**：① 数量不平衡（用户量分布不均）；② 数据漂移（训练集与测试集分布不同）；③ 数据非独立（不同用户端独立产生、分布各异）。
- **激励机制**：客户端参与要耗计算/通信/能源，需设计激励——但**贡献评估难**（难衡量数据质量与贡献）、**奖励分配难**（要公平合理）、**参与积极性不足**。

### 4. 关键技术

**隐私保护**：

- **差分隐私（Differential Privacy）**：向梯度/参数**添加噪声**，防止攻击者从模型更新中**反推单个客户端数据**；
- **同态加密（Homomorphic Encryption）**：支持**密文状态下直接计算**，服务器**不解密**即可完成模型聚合。

**通信优化**：

- **梯度压缩（Gradient Compression）**：减少传输的梯度数量——**随机稀疏化**（随机选部分）、**Top-K 稀疏化**（只传绝对值最大的 K 个）、**阈值稀疏化**（只传绝对值超阈值的）；
- **梯度量化（Gradient Quantization）**：降低梯度表示精度以减少通信量（呼应第七章量化思想）。

### 5. 三大分类（★★ 最高频考点）

按多参与方之间**数据分布**的不同划分：

|类型|数据切分|特征重叠|样本(ID)重叠|本质|典型例子|
|---|---|---|---|---|---|
|**横向联邦**|横向切分|**高**（特征一致）|低|**样本的联合**|不同地区的同业银行/零售商|
|**纵向联邦**|纵向切分|低|**高**（用户交集大）|**特征的联合**|同地的银行 + 电商|
|**迁移联邦**|—|低|低|解决标签少/数据不足|跨国的银行 + 电商/保险|

#### ① 横向联邦学习（特征相同、样本不同）

- **框架**：类似 Master/Worker——每个参与方是 Worker 本地算梯度，数据中心（Master/Parameter Server）统一收集聚合。**四步**：各方从 Server 下载最新模型 → 本地算梯度并**加密上传** → Server 聚合更新参数 → 下发，各方更新本地模型。
- **难点**：不能传数据、非独立同分布、数据量悬殊、客户端规模远超传统 Worker、通信延迟高网络不稳需高容错、数据动态变化。
- **解决方案**：每轮选占比 **C** 的客户端（要求**充电中 + 连 WiFi**）参与；其余照标准流程。
- **★ FederatedAveraging（FedAvg）**：因每算一次梯度就上传会使通信成本过高、效率低，故让客户端**本地多轮累积更新**后再上传参数增量，**减少通信次数**。

#### ② 纵向联邦学习（样本相同、特征不同）

适用于用户交集大、特征互补的两方（如银行的收支信用 + 电商的浏览购买）。设 B 有带标签数据，找 A 扩展特征，流程：

1. **样本加密对齐**：A、B 各把**加密后的用户 ID** 上传第三方 C，找出**共同用户**；
2. **模型加密训练**：C 创建加密对、下发公钥 → A、B 各算与自身特征相关的中间结果并**加密交互**求各自梯度与损失 → A、B 算加密梯度并加**掩码**（B 还算加密损失）后发给 C → C **解密**梯度与损失回传 → A、B **去掩码并更新模型**。

#### ③ 联邦迁移学习（特征 X、标签 Y、样本 ID 都不同）

用于**标签样本少、数据集不足**的跨域场景（如跨国、跨部门数据难交流）。例：两个城市的银行 + 保险公司合作开发风控模型。

### 6. 应用场景与发展趋势

**应用**：政务（成都公共数据平台，融合联邦学习+隐私计算）、医疗（腾讯天衍+微众基于 **FATE** 框架，医院数据不出本地联合建模，脑卒中预测接近集中式）、金融（微众用**纵向联邦**做多机构联合风控）、智能设备（Google **Gboard** 用 TensorFlow Federated 本地学打字习惯）。

**趋势**：与同态加密/安全多方计算/差分隐私**深度融合**、跨领域联合、通信效率优化（模型压缩/梯度量化/剪枝）、**与边缘计算融合**（低延迟分布式训练推理）。

# 第九章 区块链

### 1. 为什么需要区块链：从两个案例到"去中心化信用"

课件用两个案例切入信任危机：

- **津巴布韦货币贬值**：2008 年通胀率高达 2.31 亿%，2009 年发行面值 100 万亿纸币——本质是**国家信用（央行这一个中心）的破产**；
- **麦道夫世纪骗局**：华尔街传奇用**庞氏骗局**（借新还旧）诈骗约 500 亿美元——本质是**个人信用中心 + 不透明、无监管**的崩塌。

两案例的共同病根：**信用来自单一中心、不透明、无监管**。区块链的核心使命就是——**建立去中心化的信用**。2008 年中本聪发表比特币论文，2009 年诞生不受任何央行控制的比特币，并生成**创世区块**，在其中留下一句永不可改的话（引自当日《泰晤士报》头条），既是时间戳，也是宣言。

### 2. 区块链五大特征（★ 必考）

|特征|含义|
|---|---|
|**完全分布式**|任一节点损坏/失去都不影响系统运作|
|**可靠性与不可篡改**|要破坏系统需攻击 **51% 以上节点**|
|**去信任性**|节点间交换数据无需互信（每个节点都有全网数据）|
|**集体维护**|数据块由所有具维护功能的节点共同维护，任何人可参与|
|**完全透明**|规则（算法）与数据（账本）公开透明、可即时审计|

### 3. 区块链是什么（三视角定义）

- **数据角度**：一种几乎不可能被更改的**分布式数据库**（分布式存储 + 分布式记录）；
- **效果角度**：记录时间先后的、不可篡改的、可信任的数据库；
- **技术角度**：多种现有技术（加密算法、P2P 传输等）的新结构整合。

> **结论定义（建议背）**：区块链是**把区块以链的方式组合起来的数据结构**，适合存储简单的、有先后关系的、能在系统内验证的数据，**用密码学保证不可篡改与不可伪造**，使参与者对全网交易的**顺序与当前状态建立共识**。

### 4. 三类链（按开放程度，必考）

|类型|接入|特点|例|
|---|---|---|---|
|**公有链**|任意节点自由接入、读写不受限|完全去中心化|比特币|
|**私有链**|限定在一个实体内、由其控制|仅内部开放、保留部分去中心化|企业内部|
|**联盟链**|若干机构联合发起、适度对外|介于两者之间，最贴合多数行业|R3CEV|

### 5. 核心技术（★★ 技术重点）

#### （1）区块结构 + 哈希链

每个区块 = **区块头 + 区块体**：

- **区块头**：**父区块哈希(Previous Hash)** + **时间戳(Timestamp)** + **默克尔树根(Merkle Root)**；
- **区块体**：一串**交易列表**。
- **链式连接的本质**：区块头里保存**父区块哈希**，唯一指定父区块——任何对历史区块的改动都会使其哈希变化、断裂整条链，这就是"**不可篡改**"的来源。

#### （2）默克尔树 Merkle Tree

当前区块所有交易的一个**哈希二叉树**：先对每笔交易算哈希 → **两两分组**再算哈希（奇数则末项自身再哈希）→ 重复直至剩一个**根哈希**。作用：**高效验证 + 精准定位篡改**——只需验根哈希；不通过则逐层下探到叶子，最终准确识别被篡改的那笔交易。还支持只保留对自己有用的交易、其余备份在别处。

#### （3）数字签名（非对称加密）

每个节点持有**公私钥对**。发交易时用**私钥签名**附在交易中；其他节点用**公钥验签**，完成**完整性校验 + 发送者身份合法性校验**后才触发后续处理。

#### （4）交易过程五步（★ 含 POW 共识）

1. **制单**：所有者 A 用**私钥**对"前一次交易来源 + 下一位所有者 B"签数字签名，制成交易单（**B 以公钥作接收地址**）；
2. **广播**：A 把交易单广播全网，各节点纳入待打包区块；
3. **挖矿（解数学难题）**：节点反复试 **Nonce**，把"Nonce + 上一区块哈希 + 交易单"送入 **SHA256**，使输出 256 位哈希满足条件（如前若干位为 0）即解出难题，**获记账权并奖励比特币**；
4. **广播+验证**：找到解者向全网广播带时间戳的区块，其他节点核对；
5. **竞争下一区块**：核对无误后，各节点在该合法区块后竞争下一个，形成合法链。

> **难度自适应**：每区块约 **10 分钟**；系统按最近 **2016 个区块**（约两周）的时间差自动调难度（增减目标值中 0 的个数），使出块时间稳定在 10 分钟。一笔比特币通常需 **6 个区块确认**才真正到账。

#### （5）共识机制：工作量证明 POW

**所有分布式节点如何达成共识** = 既是认定记录有效的手段，也是防篡改手段。POW 的核心是**不对称性**：**工作（求解）对请求方适中、对验证方极易**；伪造/篡改需要上亿成本的算力，故有效防伪。

#### （6）节点网络与分叉

- **完整节点四功能**：钱包（交易）、完整区块链（验证新交易）、矿工（出块赚奖励）、路由（转发）。
- **分叉**：同一时段可能多个节点都算出合法区块并广播 → 节点本地建多分支 → 僵局由**下一个 POW**打破，**较长的链被证实，短分支被抛弃，节点转向最长链**（**最长链原则**）。

### 6. 区块链 2.0：以太坊 + 智能合约

- **演进**：比特币（数字货币）= **区块链 1.0**；**以太坊**在数字货币基础上加**智能合约** = **区块链 2.0**。两者都是公开无许可、用 POW 挖矿、内置数字货币；区别在**以太坊出块更快、区块更小，且 EVM 上可运行智能合约**。
- **智能合约**：运行在安全环境、可控制数字资产的**计算机程序**。法律合约是"我承诺…就给你钱"，智能合约是"我把钱发给程序，条件满足程序自动执行"。优点：**自动处理、可扩展到非金融、带一定智能**。例：球赛打赌——双方把钱存入合约，结果触发后自动划账，**无需第三方裁决、无赖账**。
- **安全问题**：合约由程序员编写，**易有逻辑漏洞**；高级语言的不确定指令可能造成节点状态分歧、破坏一致性。改进：限制用**确定性语言**（以太坊 **Solidity**）。典型教训 **The DAO 事件（2016）**：转账函数漏洞被攻击者盗走 360 万以太币，以太坊最终**回滚硬分叉**挽损。

### 7. 应用与发展（了解）

- **应用分层**：1.0 数字货币；2.0 智能合约（跨境支付、反洗钱、证券、数字资产）；3.0 扩展到金融外行业（隐私数据存储、防伪溯源、身份认证、能源管理、投票）。产业实例：ICO、供应链管理、智慧农业电商。
- **三大时代**：可编程货币 → 可编程金融 → 可编程社会（走向分布式自治）。
- **区块链 vs 比特币**：比特币是**应用**（一种分布式数字货币），区块链是**一系列技术的统称**；比特币是区块链的**第一个但非唯一**应用，区块链的影响远大于比特币本身。

### 8. 现存问题与缺点（易考对比）

|维度|问题|
|---|---|
|**性能与容量**|去中心化程度 ↔ 共识效率的矛盾（越去中心化、时延越长吞吐越低）；账本增长抬高节点硬件门槛|
|**安全性**|**51% 攻击**（节点太少易得手）、私钥/终端安全（私钥被盗即损失）、PoW/PoS 安全缺严格证明|
|**应用**|缺统一标准、衍生市场混乱（假币欺诈）、缺落地场景、技术不成熟、人才匮乏、认知接受度低|
|**固有缺点**|**不可篡改/撤销**（转错地址或丢私钥永久损失，不像银行可补救）、**数据公开无隐私**、**性能问题**（需下载全账本、追溯每笔算余额）、**数据延迟**（比特币约 10 分钟 + 分叉问题）、**高能耗**|

### 全章主线

### 5.1 感通一体化 ISAC

**定义**：把无线**感知与通信集成**在一起，**共享硬件与频谱资源**，实现两者深度协作（甚至互利）。背景：过去感知靠专用设备（雷达/激光雷达），5G 里定位是唯一感知服务；如今 5G/6G + 自动驾驶等要求"高速通信 + 精确感知"并存。

**三大物理基础**：**毫米波**（30–300GHz 超大带宽、数十 Gbps、厘米级测量）、**大规模 MIMO**（数百天线、高维 CSI、亚米级分辨率、三维重构）、**波束赋形**（可编程相控阵、实时定向、避免全向能耗浪费）。

**挑战**：宏观三类——通感能力（速率↔精度权衡）、网络效率（资源共享与复杂度）、网络质量（抗干扰/可靠性）。具体五点——通感性能折中、感知精度不足（收发难理想同步→相位误差）、干扰控制复杂、多节点协作同步难、复杂网络下高精度感知（需识别 **LOS / NLOS** 路径）。

#### 5.1.1 两种工作模式（★ 必考对比）

| |**被动感知**|**主动感知**|
|---|---|---|
|机制|利用**现有通信信号的反射波**感知环境|**智能波形设计**：FMCW 雷达线性调频 + OFDM 通信波形融合|
|部署|监视信道、解析反射，同时用直接信道维持通信|自适应波束：**窄波束**高精度测距测速、**宽波束**保通信覆盖|
|优势|**"零附加能耗"**，无需专用设备，适合低功耗大规模 IoT|V2X 已实现**厘米级定位 + Gb 级通信**同步|
|例|智能家居分析 **Wi-Fi CSI** 检测人体/跌倒；工业 IoT 用 5G 反射监测设备|车联网 V2X|

**三类实现路径（按资源共享程度）**：**高共享度**（硬件+波形全共享，频谱/能耗最优但精度覆盖不足）、**中共享度**（硬件共享、波形时分复用，通感平衡，**当前主流**）、**低共享度**（分立硬件与频段，双方性能最优但冗余浪费）。可用**深度强化学习**动态选模式（智慧城市平时被动广域监测、异常时切主动精细感知）。

#### 5.1.2 三大关键技术

**① 波束赋形**：动态调发射方向与形状。调度策略——**时间分片**（感知/通信按时间轮换）、**波束复用**（多功能波束叠加同时服务）、**波束切换**（按优先级快速切换）。联合优化两向：**感知驱动通信**（用目标位置预配置波束）+ **通信辅助感知**（用信道信息优化感知波束），配强化学习/博弈论闭环。

**② 干扰消除**：ISAC 上下行同频并发，需消除**三类自干扰——天线 / 射频 / 数字**。手段：智能干扰识别（空间域波束抑制）、用户波束选择（感知→特征提取→建模→决策四阶段）、网络级管理（动态频谱+功率控制）。

**③ 参数估计**（精确感知与通信的基础，三方法对比，★ 考点）：

|方法|特点|
|---|---|
|**最小二乘 LS**|计算简单、无需先验统计；**噪声敏感**|
|**最小均方误差 MMSE**|利用信道统计特性，性能优于 LS；复杂度较高|
|**最大似然 ML**|**渐近最优、精度最高**；复杂度最高|

#### 5.1.3 应用六大领域

自动驾驶（距离/速度/角度 + V2I/V2V 编队）、智能交通 ITS、无线定位导航（GPS 受阻备选）、环境监测、工业自动化、健康监测。

### 5.2 跨技术通信 CTC

**定义**：在遵循**不同无线标准的异构设备间直接通信**。背景：Wi-Fi、ZigBee、BLE 共用 **2.4GHz**，但调制方式差异大、互不了解对方收发时机，造成冲突。传统方案局限——**TDMA**要求通用标准（不适异构）、**CSMA**避碰撞但频谱效率低。

#### 两类实现（★ 必考对比）

| |**数据包级 CTC**|**物理层 CTC（WEBee）**|
|---|---|---|
|原理|标准不兼容、无法互解码，靠**信号能量特征**通信|**QAM 仿真**：把 Wi-Fi 数据包 Payload **模拟成 ZigBee 所需信号特征**|
|方式|ZigBee 端设固定 CTC 符号窗口，检测 Wi-Fi 包能量：有能量=**"1"**、无=**"0"**，用包发射间隔编码|ZigBee 接收器能正确解码经 Wi-Fi 发的包、无法区分来源；Wi-Fi 接收器也能正常处理|
|局限|未充分利用带宽、**频谱效率低、速率受限**|解决了数据包级的低效问题|

**WEBee 的 QAM 拟合**：把 ZigBee 所需时域波形经 **FFT** 算出对应 QAM 星座点（时域→频域，复数星座点表相位幅度），初步调制有偏差则**优化校正**，使误差落入 ZigBee 接收器容忍范围。

**应用与展望**：无源 ZigBee + 反向散射中继（功耗仅 25µW）、多设备协同动态频谱共享。**TiFi 跨频段通信**——突破"频段必须重叠"的限制：利用 **RFID 标签天线非线性产生的谐波**（基频 820MHz 反射出 1.64/2.46GHz 高次谐波，**恰与 Wi-Fi 2.4GHz 重叠**），阅读器按 Wi-Fi 波形重新调制 RFID 数据，Wi-Fi 接收器即可解码。趋势：**跨网络、跨频率、跨媒体** + 动态频谱接入。

### 5.3 侧信道通信（兼具传输与安全意味）

**原理**：电子设备运行必然产生**功耗、电磁辐射、声音、温度**等物理量变化。核心关联：低压=**"0"**、高压=**"1"**；相邻比特相同(00/11)→静态消耗、泄露平稳，相邻不同(01/10)→动态消耗、泄露更显著。两大依赖：**数据依赖性**（数据影响泄露特征）+ **操作依赖性**（不同计算过程映射不同泄露）。

**被动式：TEMPEST 窃听**——1985 年 van Eck 发现**显示器电磁辐射含画面信息**，数百米外用接收机+定向天线即可逆向还原。**Deep-TEMPEST（2024）**用 **CNN** 学习恢复粗糙画面，实现近乎无损窃听（AI × 传统 TEMPEST）。

**主动式：隐蔽通信**——主动操纵侧信道辐射对数据编码发射，典型用于窃取**物理隔离计算机**（已移除 Wi-Fi/蓝牙/网卡）的秘密：植入木马（如 **Stuxnet**）→ 操控硬件电磁/声学辐射编码 → 附近接收机解码。

**两个研究案例**：

- **USBee（2014）**：在 USB2.0 设备上读写特殊 01 序列，操纵 **D+/D-** 数据线电压波动调制电磁辐射频率（**NRZI 编码**：'0' 电平变化、'1' 电平不变，交替 01 产生方波），精确控频（如 200MHz）编码秘密数据；
- **ScreenInformer**：LCD **电容啸叫**（电容充放电振动撞 PCB 产高频噪声），播放**黑白条纹图**刺激显示器发特定频率声音，泄露频率 **F = (YH / 2·SH)·RA**（YH 屏幕像素高、SH 条纹像素高、RA 刷新率；SH=5px → F≈6480Hz），附近麦克风捕捉解调。
