# LLM Research Wiki

一个静态、双语的 LLM mechanistic interpretability 辅助研究网站。目录严格按 `Research Wiki.md` 组织。

## 使用

直接用浏览器打开 `index.html`。网站包含：

- 左侧完整目录，可定位到文章和文章内小节
- 博客式长文正文，而不是卡片式排版
- 每个小节包含数学原理、使用场景、优缺点、核心代码示例、引用
- 每个小节包含可能的可视化方式，并链接到论文/项目页中的原始图源
- 正文引用采用右上角角标，角标可跳转到参考文献页
- 简体中文 / English 语言切换
- 站内搜索和参考文献页

## 文件

- `index.html`：页面结构
- `styles.css`：视觉样式与响应式布局
- `app.js`：目录数据、双语内容、hash 路由、搜索和渲染逻辑
- `Research Wiki.md`：原始目录来源
